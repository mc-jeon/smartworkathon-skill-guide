복사·붙여넣기로 완성하는 AI 스킬

AI를 잘 몰라도 괜찮습니다. 화면 순서대로 복사하고 붙여넣기만 하면, 상품 정보 하나로 마케팅 콘텐츠를 한 번에 만드는 나만의 AI 스킬이 완성됩니다.

먼저 영상으로 한 번 보기전체 흐름을 보고 시작하면 훨씬 쉽습니다

🎬 따라 하기 영상 준비 중영상이 올라오면 이 자리에서 바로 볼 수 있습니다.

STEP 2-2

스킬 만드는 프롬프트 보내기

🎯 AI에게 과제 조건에 맞는 스킬 설명서 초안을 만들게 합니다.
  1. AI 화면 왼쪽 위 ＋ 새 채팅을 누릅니다
  2. 아래 상자의 복사를 누릅니다
  3. 입력창에 Ctrl+V로 붙여넣고, [내가 만들고 싶은 콘텐츠] 아래 줄과 [내 스킬만의 특징] 아래 줄만 2-1에서 고른 것으로 바꿉니다
  4. ↑(보내기)를 누릅니다
너는 마케팅 업무를 돕는 'AI 스킬'을 설계하는 전문가야. 아래 [과제 조건]을 모두 지키는 '스킬 설명서'를 만들어 줘. 이 설명서는 다른 AI 채팅에 그대로 붙여넣으면 바로 작동해야 해. [과제 조건] 1. 상품 특징과 홍보 대상을 입력받아 모든 콘텐츠에 반영한다. 2. 콘텐츠마다 제작 절차(순서)와 출력 형식(분량, 구성, 해시태그 수 등)을 정확히 적는다. 3. 특정 상품 이름을 넣지 말고, 어떤 상품이든 다시 쓸 수 있게 만든다. 4. 입력에 없는 성능·가격·수치·인증·후기는 절대 지어내지 않는다. 정보가 없으면 [확인 필요]라고 표시한다. 5. 모든 결과물은 시험용 초안이며, 실제 게시·광고 집행·유료 결제는 하지 않는다. [내가 만들고 싶은 콘텐츠] 인스타그램 게시글, 네이버 블로그 글, 카카오톡 채널 홍보 메시지 [내 스킬만의 특징] 없음 [스킬 설명서 구성] 아래 번호와 제목을 그대로 써 줘. 0. 스킬 이름과 한 줄 설명 1. 입력받을 정보 (빈칸 양식 포함, 빠진 정보가 있으면 먼저 질문하기) 2. 꼭 지킬 규칙 3. 콘텐츠별 제작 절차와 출력 형식 4. 결과를 내기 전 스스로 점검할 항목 5. 최종 출력 순서 [작성 방법] - 메모장에 저장할 것이므로 표, 굵은 글씨(**), # 기호, 코드 상자 없이 일반 글자와 번호, - 기호만 써 줘. - 설명서 본문만 보여 주고, 앞뒤 인사말은 빼 줘.
고치는 곳은 딱 두 줄 예) 인스타그램 게시글, 숏폼 영상 대본(30초), 문자(SMS) 문구 / 특징: 콘텐츠마다 제목 후보를 2개씩 제안한다. 나머지는 그대로 두세요 — 과제 조건이 이미 들어 있습니다.
'0. 스킬 이름과 한 줄 설명'부터 '5. 최종 출력 순서'까지 번호가 붙은 설명서가 나오면 성공입니다.
표나 ** 기호가 섞여 나오면 "메모장용 일반 글자로 다시 써 줘"라고 보내세요. 답이 중간에 끊기면 "계속"이라고 보내세요. 입력창에서 줄을 바꾸려면 Shift+Enter입니다.
STEP 2-3

  1. AI 답변 바로 아래의 ⧉ 복사 아이콘을 누릅니다
  2. 메모장을 누르고 Ctrl+V로 붙여넣습니다
  3. 메뉴 파일 → 다른 이름으로 저장을 누릅니다
  4. 파일 이름에 트랙B_스킬_내이름.txt를 입력하고, 인코딩이 UTF-8인지 확인한 뒤 저장을 누릅니다
메모장 맨 위 제목이 '트랙B_스킬_내이름.txt - 메모장'으로 바뀌면 성공입니다. 저장 위치(보통 '문서' 폴더)를 기억해 두세요.
복사 아이콘이 안 보이면 답변 위에 마우스를 올려 보세요. 그래도 없으면 답변 글을 마우스로 끌어 선택한 뒤 Ctrl+C. 맥 텍스트 편집기는 파일 → 저장에서 '일반 텍스트 인코딩: 유니코드(UTF-8)'를 고르세요.
💻 실습은 PC에서 프롬프트 붙여넣기·메모장 저장은 PC에서 하세요. 휴대폰에서는 화면 확인·복습용으로 보세요. 그림은 탭하면 크게 볼 수 있습니다.

3. 스킬 실행해 보기약 15분 · 심사위원처럼 '처음 보는 AI'에게 스킬을 줘 봅니다

왜 새 채팅에서 하나요? 스킬을 만든 대화에는 이미 많은 설명이 쌓여 있어서, 설명서가 부족해도 AI가 눈치로 채워 줍니다. 새 채팅에서 설명서만 주고도 잘 돌아가야 진짜 '다시 쓸 수 있는 스킬'입니다.
STEP 3-1

새 채팅에 스킬 설명서 넣기

🎯 아무것도 모르는 새 채팅에 내 스킬을 알려 줍니다.
  1. ＋ 새 채팅을 누릅니다
  2. 아래 시작 문장을 복사해 입력창에 Ctrl+V로 붙여넣습니다
  3. Shift+Enter를 두 번 눌러 줄을 띄웁니다
  4. 메모장에서 Ctrl+A(전체 선택) → Ctrl+C(복사) 후, 입력창에 다시 Ctrl+V
  5. ↑(보내기)를 누릅니다
지금부터 붙여넣는 글은 '스킬 설명서'야. 앞으로 이 설명서대로만 일해 줘. 다 읽었으면 다른 말 없이 "상품 정보를 보내 주세요"라고만 답해 줘.
AI가 "상품 정보를 보내 주세요"라고 답하면 성공입니다.
AI가 바로 콘텐츠를 만들어 버리면 괜찮습니다. 다음 단계로 상품 정보를 보내면 됩니다. 입력창에 붙여넣기 대신 📎(파일 첨부)로 txt 파일을 올리고 시작 문장만 보내도 됩니다.
STEP 3-2

샘플 상품 정보 보내기

🎯 가상 상품 '감귤잼' 정보로 스킬을 실제로 돌려 봅니다.
  1. 아래 상자의 복사를 누릅니다
  2. 같은 채팅 입력창에 Ctrl+V 후 보내기
[상품 정보] ※ 실습용 가상 상품입니다 - 상품명: 귤빛담은 수제 감귤잼 - 판매자: 제주 소규모 농가 브랜드 '돌담귤방' - 상품 특징: 1) 제주에서 기른 감귤로 만든 잼 2) 정제 설탕 대신 비정제 원당 사용 3) 보존료·색소를 넣지 않음 4) 일주일에 두 번, 소량씩 끓여 만듦 5) 유리병 1개 240g - 홍보 대상: 아이 간식을 고르는 30~40대 부모, 간단한 아침을 챙기는 1인 가구 - 홍보 목적: 신제품 출시 알림 - 가격: (제공되지 않음)
가격 칸은 일부러 비워 두었습니다 스킬이 가격을 지어내지 않고 [확인 필요]로 두는지 시험하는 장치입니다.
설명서에 정한 콘텐츠가 정한 순서대로 나오고, 가격 자리에는 숫자 대신 [확인 필요]가 보이면 성공입니다.
AI가 "가격을 알려 주세요"처럼 먼저 물어보면 정상입니다(빠진 정보를 묻도록 설명서에 적었기 때문). 아래 문장을 보내세요.
가격 정보는 없어. 가격은 [확인 필요]로 두고 그대로 진행해 줘.
STEP 3-3

출력물 저장하기

🎯 심사 보조자료로 낼 '샘플 출력물'을 파일로 저장합니다.
  1. AI 답변 아래 ⧉ 복사를 누릅니다
  2. 메모장에서 Ctrl+N(새 탭)을 누르고 Ctrl+V로 붙여넣습니다
  3. 파일 → 다른 이름으로 저장 → 파일 이름 트랙B_출력물_감귤잼_내이름.txt → 저장
메모장 위쪽에 탭이 두 개(스킬, 출력물) 보이면 성공입니다.
💻 실습은 PC에서 프롬프트 붙여넣기·메모장 저장은 PC에서 하세요. 휴대폰에서는 화면 확인·복습용으로 보세요. 그림은 탭하면 크게 볼 수 있습니다.

STEP 4-1

결과물 점검 시키기

🎯 AI에게 방금 결과가 규칙을 지켰는지 스스로 점검하게 합니다.
  1. 3-2를 한 같은 채팅에서 아래 상자의 복사를 누릅니다
  2. 입력창에 Ctrl+V 후 보내기
방금 만든 결과물을 스킬 설명서의 규칙과 비교해서 점검해 줘. 아래 형식으로만 답해 줘. 1. 상품 정보에 없는데 지어낸 내용(성능·가격·수치·후기): 있으면 그 문장을 그대로 옮기고, 없으면 "없음" 2. 홍보 대상이 반영된 곳: 콘텐츠마다 한 줄씩 3. 출력 형식(분량·구성·해시태그 수 등)을 어긴 곳: 있으면 콘텐츠 이름과 함께, 없으면 "없음" 4. 1번이나 3번에 문제가 있었다면, 고친 결과물 전체
1번(지어낸 내용)과 3번(형식 어긴 곳)이 모두 "없음"이면 통과입니다. 문제가 있었다면 4번에 고친 결과가 나오니, 그것으로 출력물 파일을 바꿔 저장하세요.
1번에 문제가 나왔다면 출력물만 고치지 말고, 4-3에서 스킬 설명서도 고쳐야 다음에도 같은 실수를 하지 않습니다.
STEP 4-2

다른 상품으로 재사용 시험

🎯 필수 요구사항 ③(다른 상품에도 다시 쓸 수 있음)을 확인합니다.
  1. ＋ 새 채팅을 누르고 3-1과 똑같이 시작 문장 + 스킬 설명서를 보냅니다
  2. 아래 두 번째 샘플 상품을 복사 → 붙여넣기 → 보내기
[상품 정보] ※ 실습용 가상 상품입니다 - 상품명: 폴딩업 노트북 거치대 - 판매자: 사무용품 소기업 '데스크온' - 상품 특징: 1) 알루미늄 소재 2) 높이를 6단계로 조절 3) 접으면 두께 2cm 4) 무게 280g 5) 10~16인치 노트북에 사용 - 홍보 대상: 카페·공유오피스에서 일하는 직장인, 집에서 일하는 재택근무자 - 홍보 목적: 새 학기·연말 업무용 선물 추천 - 가격: (제공되지 않음)
감귤잼 때와 같은 구성·같은 순서로, 노트북 거치대에 맞는 내용이 나오면 성공입니다.
결과에 '감귤', '아이 간식'처럼 첫 번째 상품 이야기가 섞이면 설명서 안에 특정 상품이 들어가 있다는 뜻입니다. 4-3에서 "특정 상품 이야기를 모두 빼 줘"로 고치세요.
STEP 4-3

스킬 설명서 고치기

🎯 시험에서 나온 문제를 설명서에 반영해 더 좋은 스킬로 만듭니다.
  1. 왼쪽 최근 대화에서 스킬을 만들었던 대화(마케팅 스킬 만들기 등)를 누릅니다
  2. 아래 상자를 복사 → 입력창에 붙여넣고, [문제] 아래 줄을 내가 겪은 문제로 바꿉니다
  3. 보내기를 누릅니다
  4. 새로 나온 설명서를 ⧉ 복사 → 메모장의 스킬 탭에서 Ctrl+A → Ctrl+V → Ctrl+S(저장)
스킬 설명서를 시험해 봤더니 아래 문제가 있었어. 문제를 고친 설명서 전체를 처음부터 끝까지 다시 써 줘. (번호와 제목은 그대로, 메모장용 일반 글자로) [문제] 블로그 글이 너무 길었다
이런 문제가 있었다면[문제] 칸에 이렇게 쓰세요
글이 너무 길다블로그 글은 800자 안쪽으로 줄이는 규칙을 넣어 줘
해시태그가 너무 많다해시태그는 5개로 정해 줘
가격·수치를 지어냈다입력에 없는 숫자는 쓰지 말고 [확인 필요]로 쓰라는 규칙을 더 분명하게 넣어 줘
다른 상품 이야기가 섞였다설명서 안의 특정 상품 이야기를 모두 빼 줘
말투가 대상과 안 맞다홍보 대상의 나이와 상황에 맞게 말투를 바꾸는 절차를 넣어 줘
고친 설명서로 3-1~3-2를 새 채팅에서 다시 돌렸을 때 문제가 사라지면 성공입니다. 출력물 파일도 새 결과로 바꿔 저장하세요.

STEP 5-1

과제 조건 최종 점검

🎯 내 스킬이 과제 조건을 모두 채웠는지 AI와 함께 확인합니다.
  1. ＋ 새 채팅을 누르고 아래 상자를 복사 → 붙여넣기
  2. 이어서 메모장의 스킬 설명서 전체를 Ctrl+A → Ctrl+C → 입력창 끝에 Ctrl+V → 보내기
  3. '부족'이 나온 조건은 알려 준 문장을 메모장 설명서의 알맞은 번호 아래에 붙여넣고 저장합니다
아래 [과제 조건]과 [내 스킬 설명서]를 비교해서 점검해 줘. 조건마다 "충족 / 부족" 중 하나로 답하고, 부족하면 설명서에 추가할 문장을 알려 줘. 설명서를 새로 쓰지는 마. [과제 조건] 1. 상품 특징과 홍보 대상을 입력받아 반영하는가 2. 콘텐츠별 제작 절차와 출력 형식이 적혀 있는가 3. 특정 상품에 묶이지 않고 다른 상품에도 다시 쓸 수 있는가 4. 제공되지 않은 성능·가격을 지어내지 말라는 규칙이 있는가 5. 시험용으로만 만들고 실제 게시·유료 결제를 하지 말라는 규칙이 있는가 [내 스킬 설명서]
다섯 조건이 모두 '충족'이면 끝입니다.
